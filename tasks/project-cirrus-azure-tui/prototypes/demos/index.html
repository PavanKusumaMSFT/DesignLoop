Project Cirrus — Prototype Demos

Inline, non-modal Azure CLI intelligence layer · self-contained, no build step

Each demo is interactive and token-driven (colors/typography from designs/tokens/tokens.css). Switch theme on any page to verify contrast across dark / light / high-contrast, and toggle reduce motion to confirm animations degrade to none. Keyboard: ↑↓ move · Tab accept · Esc exits · Enter is never hijacked.
