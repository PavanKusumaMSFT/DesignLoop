# How Might We Questions: CLI AI Opportunities

## Overview

These questions open the solution space while retaining the study’s priorities: contextual command discovery, lower validation burden, subtle prevention, and explicit control.

1. How might we help a person turn an intended outcome into a valid CLI starting point without forcing them out of their workflow?
2. How might we make a suggested command easier to assess than a plausible unvalidated answer?
3. How might we catch likely syntax mistakes while leaving typing and execution under the person’s control?
4. How might we expose the boundary between checked syntax and uncheckable environment constraints?
5. How might we give terminal and IDE users appropriate, opt-in paths without assuming one workflow?
